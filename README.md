# volt-agents — как пользоваться и как делать своих агентов

«Штаб» ИИ-команды ВОЛЬТ. Здесь 4 маркетинговых субагента и библиотека из
50 навыков. Позже расширим до стратегов/советников.

---

## 1. Как запустить
Откройте **эту папку** (`volt-agents`) как проект в Claude Code (в десктоп-
приложении — выбрать папку проекта, либо в терминале `cd volt-agents` и
запустить `claude`). Тогда подхватятся агенты из `.claude/agents` и навыки из
`.claude/skills`, а общий контекст бизнеса — из `CLAUDE.md`.

## 2. Команда агентов
| Агент | За что отвечает |
|---|---|
| **marketolog** | Стратегия, маркетинг-план, позиционирование, офферы, акции, конкуренты |
| **kontent-smm** | Посты, контент-план, видео/Reels, email/SMS, лид-магниты, PR |
| **seo** | Ключи, SEO-аудит, посадочные, schema, локальное SEO по Красноярску |
| **analitik** | Метрики, воронка, A/B-тесты, атрибуция, рост конверсии, удержание |

## 3. Как вызвать агента
- **Автоматически:** просто опишите задачу — Claude сам делегирует подходящему
  агенту по его `description` (напр. «составь план продвижения на 90 дней»).
- **Явно:** «Используй агента **marketolog**: придумай 5 акций на осень».
- В десктоп-приложении можно выбрать агента в интерфейсе.

## 4. Как работают навыки (skills)
Навык — папка `.claude/skills/<имя>/SKILL.md` с `name` и `description`. Claude
сам подключает навык, когда задача подходит под описание, либо агент вызывает
его инструментом `Skill`. Описания навыков на английском (для срабатывания) —
это норма, ответы всё равно на русском (правило в `CLAUDE.md`).
Список 50 навыков: `ls .claude/skills`.

## 5. Как ДОБАВИТЬ своего агента (шаблон)
Создайте файл `.claude/agents/<имя>.md`:
```markdown
---
name: имя-латиницей            # уникальное, kebab-case
description: Когда использовать этого агента (по этому тексту идёт делегирование)
tools: Read, Write, Edit, Grep, Glob, WebSearch, WebFetch, Skill
model: sonnet                  # можно haiku (дешевле) / opus (сложнее задачи)
---

Ты — <роль>. <Зона ответственности>.
Опорные скиллы: перечисли нужные из .claude/skills.
Как работаешь: 1) … 2) … 3) …
Пиши по-русски, в голосе бренда (см. CLAUDE.md).
```
Готово — агент появится в проекте автоматически.

## 6. Как ДОБАВИТЬ навыки
- Скопируйте папку навыка в `.claude/skills/`. Готовые лежат в
  `skills-library/marketingskills/skills/` (все 50 уже установлены).
- Взять новые из большого набора (Alireza Rezvani), напр. для стратегов:
  ```bash
  git clone --depth 1 https://github.com/alirezarezvani/claude-skills
  # выберите нужные папки (НЕ всё — там ~477) и скопируйте:
  cp -r claude-skills/c-level-advisor/<навык> .claude/skills/
  ```
  Полезные разделы там: `c-level-advisor`, `business-growth`,
  `business-operations`, `agents` (мета: как строить агентов).
