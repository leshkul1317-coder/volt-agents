# Google Sheets — лог заявок URSANO RENT (структура)

> Единая таблица заявок заказ-бота. Из неё аналитик считает воронку и каналы.
> Один лист «Заявки» (сырые данные) + лист «Свод» (агрегаты по неделям — считает аналитик).

## Лист «Заявки» — колонки
| Колонка | Пример | Зачем |
|---|---|---|
| `id` | 1042 | Уникальный номер заявки |
| `datetime` | 2026-09-19 14:32 | Дата/время заявки (Asia/Krasnoyarsk) |
| `name` | Сергей | Имя клиента |
| `phone` | +7 933 … | Контакт (для связи; в аналитике не публикуем) |
| `tool` | Перфоратор П-1000-3,2 | Что заказали |
| `category` | Перфораторы | Категория каталога |
| `rent_days` | 3 | Срок аренды (дней) |
| `sum` | 1500 | Сумма аренды, ₽ |
| `channel` | vk / 2gis / site / yandex | Откуда пришёл (по UTM или `?start=` коду) |
| `utm_source` | vk | UTM-метка источника (если есть) |
| `utm_campaign` | oct-diy | UTM-метка кампании (если есть) |
| `status` | new / confirmed / delivered / returned / canceled | Стадия воронки |
| `is_repeat` | да / нет | Повторный клиент? |
| `comment` | — | Заметки оператора |

## Стадии воронки (значения `status`)
`new` → `confirmed` (подтвердили) → `delivered` (выдали) → `returned` (вернули) → при отказе `canceled`.
Аналитик по ним считает конверсии: заявка→подтверждение→выдача→возврат и % отказов.

## Метки каналов (чтобы видеть, откуда заказы)
- В идеале — **UTM** на всех ссылках в рекламе/ВК/2ГИС/Яндекс (заполняют `utm_source`/`utm_campaign`).
- Быстрый вариант без разработки — **разные `?start=` коды** для заказ-бота в каждом канале
  (напр. ссылка в ВК: `t.me/VOLT_Go_Bot?start=vk`), тогда канал видно прямо в заявке.

## Как заявки попадут в таблицу (варианты подключения)
1. **Google Apps Script Web App** (проще всего): скрипт-приёмник на стороне Google, бот/сайт
   шлёт на него POST с полями заявки — строка добавляется в лист. Не нужен сервер.
2. **n8n**: узел Telegram Trigger (или Webhook) → узел Google Sheets «Append Row».
3. **Прямой Google Sheets API** из кода бота/Cloudflare Worker.

> Что именно выбрать — зависит от того, где сейчас живёт код заказ-бота (Cloudflare Worker?).
> Нужен доступ к нему или к n8n, чтобы добавить один шаг «записать заявку в таблицу».
